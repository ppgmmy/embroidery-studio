# embroidery-studio

刺繡工作室 —— 以信仰圖騰、植物刺繡與書法字為主的刺繡品牌站。

## 主要賣點

- **可愛圖騰**：十字架、白鴿、彩虹、聖經、芥菜種、小魚等（刺繡針法呈現）
- **故事 Pattern**：方舟、牧羊人、五餅二魚、馬槽、百合十字架
- **植物線**：向日葵、野玫瑰、青色小花
- **靚字書法**：恩典、平安、喜樂、盼望、慈愛、信心
- **教學課**：`/embroidery/lessons` 逐步刺繡課

## 產品形態

手提袋、手帕、杯套、 hoop 掛牆、布貼、書籤、教學套件、改衣報價

## 開發（本機 / Cloud Agent）

```bash
npm install
npm run dev
```

預覽：

- 刺繡主頁：http://localhost:3000/embroidery
- 教學課：http://localhost:3000/embroidery/lessons
